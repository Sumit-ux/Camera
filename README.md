# PulsePay Fintech App

A lightweight fintech web app built with plain HTML, CSS, and JavaScript.

## Features
- Account balance overview
- Quick peer-to-peer transfer form with validation
- Recent transaction feed updates after transfer
- Savings goals with progress bars
- Dark/light mode toggle persisted in `localStorage`

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.
